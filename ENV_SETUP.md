# Mailchimp Setup

Add these environment variables to your Vercel project (Settings > Environment Variables):

```
MAILCHIMP_API_KEY=your-api-key-here
MAILCHIMP_LIST_ID=your-audience-id-here
```

## How to get these values

1. **API Key**: Log into Mailchimp > Profile > Extras > API Keys > Create a Key
2. **List/Audience ID**: Audience > Settings > Audience name and defaults > Audience ID
